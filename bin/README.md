# bin/

`SonicMania-PS1.exe` and `ovl/`: the PS1 executable and its code overlays (one per stage folder or act,
`units.txt` lists them), built from the RSDKv5-ps1 port at commit `6fba620c` (`make`, `RSDK_AUTOBUILD=1`: the Plus
characters stay off unless the disc carries `Data/PS1Config.txt`, see the README). SHA-256 in `SHA256SUMS`.

`VERSION.TXT` (`6fba620c`) goes on the disc; the title screen shows it bottom-left.
